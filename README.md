# Concepts by Mohammad Mortada

Portfolio hub served at https://concepts.mohammadmortada.com

Each concept lives in its own repository and is served automatically under this domain:

- /deloitte-redesign/
- /validation-calculator/
- /shamaa-concept/

To add a new concept: create a public repo, enable GitHub Pages on it with no custom domain, then add a new list item to `index.html` pointing to `/<repo-name>/`.
